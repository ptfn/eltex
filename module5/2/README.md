# Задание 2 — procfs модуль

Модуль создаёт файл `/proc/eltex_task2` для обмена данными между ядром и userspace. Использует `struct proc_ops` (адаптировано для ядра 7.0.8).

## Сборка

Собираем модуль через Makefile. Первая версия с `file_operations` не собралась — заменили на `proc_ops`.

![Сборка модуля](screen/1.png)

## Загрузка и проверка

Загружаем модуль, пишем данные через `/proc/eltex_task2`, читаем обратно.

![Загрузка, запись, чтение](screen/2.png)

## Работа модуля

После записи данные сохраняются во внутреннем буфере и возвращаются при чтении. При выгрузке модуля файл `/proc/eltex_task2` исчезает.

![Проверка записи и чтения](screen/3.png)
