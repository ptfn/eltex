# Задание 3 — Мигание лампочек клавиатуры (kbleds)

Модуль управляет светодиодами клавиатуры через ioctl KDSETLED. Управление миганием через sysfs: запись битовой маски в `/sys/kernel/kbleds/mask`.

## Сборка

Собираем модуль через Makefile. Первая версия с устаревшим API таймера не собралась — заменили `init_timer` на `timer_setup`, `del_timer` на `timer_delete_sync`.

![Сборка модуля](screen/1.png)

## Загрузка и проверка

Загружаем модуль, проверяем атрибуты в sysfs.

![Загрузка](screen/2.png)

## Работа модуля

Маска: 1 (Caps Lock), 2 (Num Lock), 4 (Scroll Lock), 7 (все лампочки). 0 — выключить мигание. Частота фиксированная. KDSETLED работает только в чистом tty.
